# GeriAgenda

## Sistema Web de Agendamento de Consultas Geriátricas Gratuitas

O GeriAgenda é um sistema web responsivo desenvolvido como Projeto Integrador II.

O sistema tem como objetivo facilitar o agendamento de consultas geriátricas gratuitas para pessoas com idade igual ou superior a 60 anos.

A proposta surgiu a partir da necessidade de evitar que os pacientes precisem chegar de madrugada ao local de atendimento para tentar conseguir uma vaga.

## Objetivo

Permitir que os pacientes possam consultar as datas e horários disponíveis e realizar o agendamento de sua consulta de forma antecipada, simples e organizada.

## Principais funcionalidades

- Cadastro de pacientes;
- Login no sistema;
- Consulta das datas disponíveis;
- Consulta dos horários disponíveis;
- Realização de agendamento;
- Consulta dos agendamentos realizados;
- Cancelamento de agendamento;
- Gerenciamento das datas e horários pelo responsável;
- Visualização dos pacientes agendados;
- Atualização do status do atendimento.

## Regras principais

- O atendimento é gratuito;
- O público-alvo possui idade igual ou superior a 60 anos;
- O atendimento é realizado uma vez por mês;
- Cada data possui limite máximo de 20 pacientes;
- O atendimento inicia às 07:30;
- Cada consulta possui duração aproximada de 40 minutos;
- Um horário não poderá ser reservado por mais de um paciente.

## Tecnologias utilizadas

- CSS3
- JavaScript ES6+
- Visual Studio Code
- Git
